# Adidas Sales Analysis 

## Overview
Analyzed **10,000+ Adidas sales records from 2020–2021** using Excel, Pandas, and Power BI to identify sales trends, regional performance, and product profitability.

## Tools Used
- **Excel** – Data cleaning and analysis
- **Pandas** – Data manipulation and analysis
- **Power BI** – Dashboard and visualization

## Key Analysis
- Compared sales performance across **2020 and 2021**.
- Analyzed sales methods and identified major sales trends.
- Performed **period-over-period comparisons** to evaluate performance changes.
- Identified the **Top 5 regions and product categories** based on operating profit.
- Analyzed operating profits exceeding **$40 million** across selected regions and categories.

## Outcome
Created interactive visualizations and dashboards to convert raw Adidas sales data into meaningful **business insights and performance trends**.
